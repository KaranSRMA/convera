# Convera

Convera is a free AI-powered conversation assistant designed for freelancers and small businesses. It helps you create professional reply suggestions for customer messages, making it easier to respond quickly and clearly.

It consists of two parts:

- `extension/` — Chrome extension that lets you select messages and request reply suggestions.
- `backend/` — FastAPI backend that sends the selected message image to Gemini and returns suggested replies.

> **Note:** Convera is only a wrapper around the Gemini API. The actual AI response is generated by Gemini, so suggestions may sometimes be incorrect, inaccurate, or inappropriate. Always review the suggested reply before sending it.

# Extension

## Load the Extension

1. Open Chrome.
2. Go to:

```text
chrome://extensions
```

3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the `extension/dist` folder.
6. The Convera extension should now appear in your extensions list.

---

# How to Use Convera

After loading the Convera extension, **open Convera first and then open the webpage** containing the messages you want to generate a reply for.

> **Important:** Convera does not currently work automatically on webpages that were already open before the extension was loaded. If the webpage was already open, refresh the page once before using Convera.

Convera currently has four main options.

### 1. Select Msgs

Click **Select Msgs**.

A selection box will appear on the webpage.

Resize and position the box so that it covers the messages you want Convera to use for generating suggestions.

---

### 2. Clear

Click **Clear** to remove the current selection.

It clears:

- The selection box from the webpage
- The captured image
- The selected area data

---

### 3. Toggle Events

The selection box can prevent clicks from reaching the webpage behind it.

**Toggle Events** switches the selection box between:

- `auto` — the box can receive mouse events.
- `none` — mouse events pass through the box to the webpage.

If you want to click or interact with something behind the selection box, toggle events to disable the box's mouse events.

Toggle it again to enable them.

---

### 4. Get Suggestion

First select the messages you want to use.

Then click **Get Suggestion**.

Convera captures the selected area and sends it to the backend, which uses Gemini to generate reply suggestions.

---

## Suggestions

After Gemini responds, Convera displays multiple suggestions.

Each suggestion contains:

- **Title** — describes the suggested reply.
- **Text** — the actual reply generated for the client.

Each suggestion has a **Copy** button.

Click the copy icon to copy the suggested text, then paste it into the messaging platform and send it yourself.

> Convera does not automatically send the message. You should review the generated text before copying and sending it.

# Backend

The backend is built with FastAPI and communicates with the Gemini API.

## 1. Create a Virtual Environment

Open a terminal inside the `backend` directory.

Create the virtual environment first:

```bash
python -m venv venv
```

Activate it.

### Windows PowerShell

```powershell
.\venv\Scripts\Activate.ps1
```

### Windows CMD

```cmd
venv\Scripts\activate
```

---

## 2. Install Requirements

After activating the virtual environment, install the dependencies:

```bash
pip install -r requirements.txt
```

---

## 3. Get a Gemini API Key

You need a Gemini API key to use Convera's AI functionality.

Create/get your API key from **Google AI Studio**.

Then open:

```text
backend/.env
```

The project already contains a placeholder:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Replace the placeholder with your actual API key:

```env
GEMINI_API_KEY=YOUR_ACTUAL_GEMINI_API_KEY
```

Do not share your API key publicly.

---

## 4. Run the Backend

From the `backend` directory, with the virtual environment activated, run:

```bash
uvicorn app.main:app --reload
```

The FastAPI backend will start locally.

You can then open the Convera extension in Chrome and use it to generate suggestions.

# AI System Prompt

The system prompt used to instruct Gemini can be edited here:

```text
backend/app/ai/service.py
```

Modify the prompt there if you want to change how Gemini understands the selected messages or how it generates reply suggestions.

# How Convera Works

The basic flow is:

```text
Select messages
       ↓
Convera captures the selected area
       ↓
Extension sends the image to the backend
       ↓
FastAPI sends it to Gemini
       ↓
Gemini generates reply suggestions
       ↓
Suggestions appear in Convera
       ↓
Copy a suggestion
       ↓
Paste it into the messaging platform
```

Convera itself does **not** generate the AI response. It acts as the interface/wrapper around the Gemini API, while Gemini generates the actual suggestions.

Because the response comes from an AI model, the generated suggestions can contain mistakes or misunderstand the conversation. Always review the response before sending it.
